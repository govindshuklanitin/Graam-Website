# GRAAM Environment Projects — Website

Rooftop solar business website + admin dashboard for GRAAM Environment Projects, Lucknow.

## 🚀 Local preview
Just open `index.html` in a browser, or run:
```bash
python3 -m http.server 8080
```
Then visit http://localhost:8080

## 🔧 Admin dashboard
Click the 🔒 icon (or go to the site and use PIN `1234`).
Change the PIN from **Profile → Admin PIN**.

## 📸 Updating the gallery
1. Log in to admin (PIN 1234)
2. Go to **Photo Gallery**
3. Upload photos from your device — they appear on the public site instantly.

> ⚠️ This version stores data in the browser. For real cross-device leads and photo
> uploads that persist across devices, a backend/database can be added later.
